Como usar o ShellBlocks

Como usar a ferramenta

O ShellBlocks permite aprender CLI montando comandos com blocos. Escolha seu contexto no seletor Missão:

  • Atividades guiadas: cada nível apresenta uma missão com objetivo. Monte seu programa e use Executar para rodá-lo e verificar o objetivo. Depois do sucesso, use Continuar para ir à próxima atividade.
  • Modo Livre (Sandbox): explore e execute comandos sem missão ou progressão pedagógica obrigatória.

A progressão das Atividades guiadas

  • Tutorial: aprender conceitos novos com instruções detalhadas.
  • Treino: praticar conceitos já apresentados com menos orientação.
  • Desafio: decidir como combinar o que foi aprendido com maior autonomia.

Aprender com orientação → praticar com menos ajuda → resolver com autonomia.

Da toolbox à montagem

A toolbox é o painel de blocos. Suas categorias agrupam famílias de comandos. Abra a subcategoria de um comando para encontrar seu bloco principal e, quando disponíveis, Opções e Operandos.

Pense assim: a subcategoria reúne o comando principal e os blocos que você pode encaixar nele.

Arraste o bloco principal da toolbox para o workspace, a área de montagem. O próximo passo é encaixá-lo no Script Principal, a raiz da montagem executável: o comando precisa estar conectado a ele para fazer parte do programa.

Opções e operandos são blocos separados. Arraste-os também para o workspace e encaixe cada um na entrada correspondente do comando.

Encaixar é diferente de aproximar

Para conectar um bloco, arraste-o e aproxime seu encaixe visual (o pequeno ‘dente’ do bloco) de um encaixe compatível. Solte quando os blocos se prenderem. Colocar um bloco perto de outro não significa conectá-lo.

Um bloco solto no workspace não faz parte do programa, mesmo que esteja perto do Script Principal. Comandos encaixados em sequência, pelos conectores superior e inferior, são executados nessa ordem.

Editar e experimentar

Você não precisa acertar de primeira: pode experimentar e voltar a ajustar a montagem.

  • Editar blocos: uma seta indica uma lista de escolhas (dropdown); clique para selecionar. Nos campos de texto editáveis, clique e digite. Algumas opções recebem um argumento próprio, digitado no campo da opção.
  • Corrigir e reorganizar: mova blocos, arraste-os para desconectar e reorganize a montagem. Para remover um bloco, arraste-o para a lixeira. No desktop, você também pode usar a opção de exclusão no menu do bloco, aberto com o botão direito.
  • Recomeçar: use Limpar montagem para começar novamente; a ação pede confirmação antes de descartar os blocos.

Trocar de missão não limpa automaticamente a montagem. Você pode reaproveitar os blocos na próxima atividade.

Montagem, código e resultado

  1. Montagem: monte e edite os blocos.
  2. Código Gerado: é atualizado ao montar e editar os blocos; gerar código não o executa.
  3. Executar: roda a montagem atual.
  4. Saída do Terminal: mostra o resultado. Limpar Saída apaga apenas esse conteúdo.
  5. Verificação da missão: nas atividades guiadas, a execução também verifica o objetivo da missão.

Arquivos e personalização estão em Arquivos e configurações avançadas. O Log do Sistema reúne detalhes técnicos.

Conceitos de CLI/Shell

O que é Linha de Comando (CLI)?

Na linha de comando, uma instrução é escrita em texto. O ShellBlocks representa visualmente as partes dessa instrução com blocos, e o Código Gerado mostra a instrução textual correspondente à montagem.

mkdir projetos

Esse comando cria uma pasta chamada projetos.

  • Comando: a ação principal, como ls ou mkdir.
  • Opção: modifica o comando, como -l. Algumas opções também recebem um argumento.
  • Operando: um valor sobre o qual o comando atua, como o nome projetos.

A ordem e as maiúsculas podem importar. Leia a missão para entender o objetivo de cada atividade.
